# 图片长图文本规则

## 一、文字准确性

1. 用户指定的文字必须逐字保留，不擅自改写、删减或增加内容。
2. 重点核对中文字符、金额、括号、冒号、日期、时间和单位。
3. 收费金额必须与用户要求一致，例如“收费：20（首单）”。
4. 日期不能用模糊的“今天”替代具体日期；用户要求具体日期时，应写成“2026年8月30日 15:08:35”这类完整格式。
5. 不添加用户未要求的水印、二维码、说明文字或其他业务信息。

## 二、收费标注

1. 默认使用红色、清晰、较粗的字体。
2. 收费文字通常放在对应照片的右下角。
3. 使用文字实际宽度计算位置，保证文字靠右、靠下，并保留少量统一内边距。
4. 不能使用固定左坐标，以免收费文字偏离右下角。
5. 文字不能遮挡照片主体或关键细节。

## 三、时间信息

1. 只有用户要求“以当前时间为准”时，才读取当前时区时间。
2. 收到时间、完成时间和耗时应分别列出，不得遗漏。
3. 耗时按照收到时间到完成时间的实际时间差计算，精确到秒时应保留秒数。
4. 推荐格式：

   - 收到时间：2026年8月30日 15:08:35
   - 完成时间：2026年8月30日 16:43:45
   - 耗时：1小时35分10秒

5. 如果跨日，必须写出完整日期，不能只写时间。
6. 若用户提供截图只是为了确认时间，截图本身不应自动放入最终图片，除非用户明确要求。

## 四、底部说明

1. 底部说明使用黑色字体。
2. 字号应小于主标题和收费标注。
3. 多行信息统一左对齐，靠近主画幅左下方。
4. 底部信息区只保留文字需要的高度和少量边距，不能留下大面积空白。
5. 行距保持紧凑，但不能造成文字粘连或难以阅读。

## 五、骑行祝福语

1. 用户要求骑行风格时，祝福语以两句为宜。
2. 可使用以下文案：

   - 祝老板早日骑到300瓦！
   - 一路顺风，功率拉满，越骑越强！

3. 祝福语使用喜庆红色字体；如用户要求黑白打印，则统一改为黑色。
4. 可加入少量红色、金色或黑色的简洁线条和圆点装饰，但不能喧宾夺主。
5. 祝福语不能遮挡照片、取件码、收费文字或时间信息。
6. 骑行祝福语应保持原意，不要擅自改成与骑行无关的营销文案。

## 六、黑白打印标签

1. 黑白标签只使用黑色文字、黑色线条和白色背景。
2. 取件码标题应醒目，填写框应足够大、边界清晰。
3. 取件码填写区域不得预填虚构数字。
4. 标签应避免灰色渐变、彩色装饰和复杂背景。
5. 文本应使用支持中文的清晰字体，适合热敏打印或普通黑白打印。

## 七、画质与编辑边界

1. 用户强调原图清晰度或“不要 AI 感”时，必须使用真实原图重新合成。
2. 只对用户要求的文字、边框、分隔线和画布区域进行处理。
3. 不对照片主体进行 AI 重绘、风格化、锐化、降噪或整体模糊。
4. 轻微柔化仅作用于外边框和照片交界处，不能影响照片主体细节。
5. 尽量避免不必要的缩放和压缩，防止原图清晰度下降。
6. 生成后检查文字是否完整、位置是否正确、日期和金额是否准确，以及是否存在多余空白。
